# TrackPilot

TrackPilot is a client onboarding tracker that helps manage clients, monitor their onboarding stages, and track basic progress.

## Features

- Add new clients
- Delete clients
- Store client data using LocalStorage
- Track onboarding stages
- Display dashboard statistics
- Fetch external leads using an API
- Submit contact form
- Responsive layout

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- LocalStorage
- REST API
- Git & GitHub

## How to Run

1. Open the project in VS Code.
2. Start a local development server using the Live Server extension or another local server.
3. Open the local server URL in your browser.
4. Open `index.html` through the local server.

A local server is required because the project uses JavaScript ES modules.
